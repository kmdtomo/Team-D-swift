# Fixture asset boundary

`Fixtures/` is the only repository location for fixture binary assets. At the
T01-02 boundary it intentionally contains no binaries: none of the candidate
images from the fixed Web-source snapshot has a license or NOTICE that permits
copying it into this iOS repository.

`asset-manifest.json` records the source observation and the only permitted
disposition for each candidate. A later task may add a binary only when it is
either regenerated by an iOS-owned, deterministic generator or independently
licensed, and its manifest entry has an approved target path and SHA-256.
The generated fixture catalog is deliberately fixed at 800×800 pixels; the
manifest policy and lint enforce that dimension for every approved target.

Run `python3 scripts/lint_t01_02.py` after changing a fixture, the manifest, or
an allow/deny list. It requires Python 3.9 or later, uses only the standard
library, and runs without the Web repository, Node, or a package installation.
